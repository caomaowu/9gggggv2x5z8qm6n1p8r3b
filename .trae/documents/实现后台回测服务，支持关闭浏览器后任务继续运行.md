## 实现后台回测服务（无数据库方案）

### 目标
创建独立的后台回测守护进程，支持关闭浏览器后任务继续运行，不使用数据库。

### 实现步骤

#### 1. 创建文件队列管理模块
- `tools/batch_backtest_app/queue_manager.py`
  - 任务队列、进度、状态文件的读写
  - 文件锁机制避免并发冲突

#### 2. 创建守护进程客户端模块
- `tools/batch_backtest_app/daemon_client.py`
  - 添加任务到队列
  - 查询队列状态和进度
  - 检查守护进程运行状态
  - 停止守护进程、清空队列

#### 3. 创建后台守护进程
- `tools/batch_backtest_daemon.py`
  - 独立运行的 Python 进程
  - 监听队列文件
  - 执行回测任务
  - 实时更新进度文件
  - 写入结果到 CSV

#### 4. 修改 UI 页面
- 修改 `pages.py` "执行回测"页面
  - 添加"前台/后台"执行选项
  - 后台执行提交到队列而非直接运行
- 添加新页面 "🔧 后台任务管理"
  - 启动/停止守护进程
  - 查看队列和进度
  - 管理任务

#### 5. 创建启动脚本
- `tools/start_daemon.bat` / `start_daemon.ps1`
  - Windows 批处理文件启动守护进程

### 技术特点
- 纯文件系统存储（JSON + CSV）
- 文件锁机制保证并发安全
- 进程间通过文件通信
- 支持进度查看和断点续传
