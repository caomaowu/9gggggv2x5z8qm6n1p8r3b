# 决策智能体提示词调优实验室 (Decision Agent Prompt Tuning Lab)

这是一个专为**决策智能体 (Decision Agent)** 设计的本地化调优工具集。

## 🎯 核心目标
1. **节省成本**：通过“数据打桩 (Mocking)”技术，固定上游智能体（指标、形态、趋势）的分析结果，每次测试仅需调用一次 LLM API。
2. **快速迭代**：提供可视化 GUI，实时修改 Prompt 并立即查看决策结果。
3. **效果验证**：自动利用历史数据中的“未来 K 线”进行回测验证，判断决策是否正确。

## 📂 目录结构
```
backend/tools/prompt_tuning/
├── local_gui.py          # [核心] 本地可视化调优工具 (GUI)
├── extract_context.py    # [辅助] 从历史报告中提取上下文数据的脚本
├── test_prompt.py        # [辅助] 命令行测试脚本
└── README.md             # 说明文档
```

## 🚀 快速开始

### 1. 启动 GUI 工具
在项目根目录下运行：
```bash
python backend/tools/prompt_tuning/local_gui.py
```

### 2. 使用流程
1. **加载数据**：
   - 点击左上角的 **"1. 加载历史报告 (JSON)"** 按钮。
   - 选择 `backend/data/history/` 目录下的任意 JSON 分析报告。
   - *提示：选择包含 `future_kline_data` 字段的报告（通常由回测生成），可以开启自动验证功能。*

2. **编辑 Prompt**：
   - 左侧文本框显示当前的 Prompt 模板。
   - 您可以直接修改文本框内容（如调整权重、增加规则、修改语气等）。
   - 修改仅在本次运行生效，不会破坏源代码。

3. **运行测试**：
   - 点击右上角的 **"🚀 运行测试"** 按钮。
   - 程序将组合您修改后的 Prompt 和提取的上下文，发送给 LLM。

4. **查看结果与验证**：
   - 右下角控制台将显示 LLM 的完整回复。
   - **验证功能**：如果数据源包含未来 K 线，系统会自动判断前两根 K 线的收盘价是否盈利：
     - **✅ 成功**：收盘价在盈利方向（做多涨/做空跌）。
     - **❌ 失败**：收盘价在亏损方向。

## 🛠️ 高级功能
- **版本切换**：支持在 `Original` (经典版) 和 `Lite` (轻量版) 两种基础模板间快速切换。
- **环境隔离**：工具会自动加载项目根目录的 `.env` 配置，确保使用正确的 API Key。

## ⚠️ 注意事项
- 本工具依赖 `tkinter`，请确保您的 Python 环境已安装该库（通常 Python 自带）。
- 验证逻辑仅作为参考，实际交易结果受滑点、手续费等因素影响。
